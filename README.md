# KJSInfo Website

KJSInfo is a modern project showcase website built to display and organize my development work, including Discord bots, tools, and other creations.

It acts as a central hub where users can explore projects, view features, and access related resources quickly and easily.

---

## 🚀 Features

* 🌐 Clean and responsive design
* 📂 Project showcase system
* 🔗 Direct links to GitHub repositories
* ⚡ Fast and lightweight performance
* 🧩 Easy to update with new projects

---

## 📁 Projects Featured

### 🔹 Discord OG Role & Viewer Bot

A Discord bot that:

* Assigns OG roles to early members
* Tracks OG users
* Displays OG lists and stats

(More projects are added over time.)

---

## 💡 Example Usage

* Open the website
* Browse available projects
* Click a project to view details or access the repo

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/wmaontop/kjsinfo.online.git
cd kjsinfo.online
```

---

### 2. Install dependencies

```bash
npm install
```

---

### 3. Run locally

```bash
npm start
```

---

### 4. Build for production

```bash
npm run build
```
